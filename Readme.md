# Chạy Frontend

## Di chuyển vào thư mục frontend

```bash
cd frontend
```

## Cài dependencies

```bash
npm install
```

## Chạy React App

```bash
npm run dev
```

Frontend chạy tại:

```bash
http://localhost:5173
```
